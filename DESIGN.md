# Mathematical Observatory

User-requested replacement visual world: a dark navy laboratory with cyan signal paths, purple structure, emerald truth states and amber critical paths. Light mode uses the same semantic vocabulary against slate-white surfaces. This is an Operate/Read product for exploring mathematical state.

Tokens: navy #0a0e1a, panel #111827, elevated #1e293b, cyan #06b6d4, violet #8b5cf6, emerald #10b981, amber #f59e0b, red #ef4444. Primary text #f1f5f9; secondary text #a5b4c9. Use Inter for interface/headings and JetBrains Mono for numeric/math content. Fonts are self-hosted for offline use.

Composition: compact branded header, persistent segmented lab navigation, dedicated overview with five informative module previews, then a broad visualization workspace beside compact inputs. Semantic panels use 16px corners, restrained glass surfaces and subtle elevation. Circuits carry the signature treatment: true signals move along luminous cyan/emerald wires, with gate values always readable. Graphs use status text and colored outlines; tables use value badges and a highlighted current row.

Accessibility: visible focus, native controls, short motion, reduced-motion alternatives, semantic tables and diagrams, live status messages, 44px touch controls, responsive layouts at 480/768/1024/1440px. Avoid constant particle effects that compete with calculations; ambient grid motion is slow, low contrast and disabled for reduced motion. The brief's explicit glass/glow/grid treatments take precedence over generic style restrictions.
